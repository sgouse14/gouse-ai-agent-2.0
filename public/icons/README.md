# Gouse AI PWA icons

The source brand icon is `gouse-ai-icon.svg`.

Production PNG assets required by the manifest:
- icon-192.png — 192x192
- icon-512.png — 512x512
- maskable-512.png — 512x512, safe-area padding for adaptive launchers
- icon-180.png — 180x180 Apple touch icon

Generate these PNGs from `gouse-ai-icon.svg` with a lossless rasterizer before production deployment. Keep the artwork centered with generous padding for the maskable variant.
